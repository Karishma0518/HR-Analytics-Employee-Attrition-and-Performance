# 📊 HR Intelligence Analysis — Power BI

An interactive **HR Intelligence Dashboard** developed using Microsoft Power BI to analyze employee attrition, performance, salary patterns, demographics, and workforce trends.

The project transforms raw HR data into meaningful insights through data cleaning, transformation, DAX measures, and interactive visualizations to support HR decision-making.

## 🎯 Project Objective

The main objective of this project is to analyze employee data and identify key HR trends, with a focus on:

- Employee attrition and attrition rate
- Employee performance
- Salary and salary ranges
- Department and job-role analysis
- Employee demographics
- Workforce distribution
- Factors associated with employee exits
- Overall HR trends and insights

## 🛠️ Tools & Technologies

- **Microsoft Power BI**
- **Power Query**
- **DAX**
- **Microsoft Excel**
- Data Visualization & Dashboarding

## 📈 Dashboard & Analysis

The Power BI dashboard provides an interactive view of HR metrics and allows users to explore employee data through different dimensions such as:

- Department
- Job Role
- Gender
- Education
- Age
- Salary
- Performance
- Attrition

The dashboard includes KPIs, charts, filters, and interactive visuals to make HR data easier to understand and analyze.

## 🔄 Data Transformation

The project includes data preparation and transformation using **Power Query**, including:

- Data cleaning
- Handling missing values
- Data type correction
- Creating salary slabs/ranges
- Creating calculated columns
- Preparing data for analysis

## 🧮 DAX & Analysis

DAX measures were created to calculate important HR metrics such as:

- Employee Count
- Attrition Count
- Attrition Rate
- Average Salary
- Performance-related metrics
